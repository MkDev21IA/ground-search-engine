# 0014 — Backend Service Architecture, Streaming API, and Real-Time Telemetry

**Status:** Accepted  
**Date:** 2026-09-23  

## Context

Following the definitive "GO" verdict from the Head-to-Head empirical benchmarks ([0012](0012-head-to-head-evaluation-and-cost-benchmark.md)), the core search-extraction-synthesis pipeline must transition from standalone terminal evaluation scripts to an accessible, high-performance web service.

To prepare for the showcase web interface ([0012](0012-head-to-head-evaluation-and-cost-benchmark.md)) and programmatic integration with external agents, the backend service must satisfy five operational requirements:
1. **Low-Latency Streaming (SSE)**: Immediate visual feedback (incremental status events and real-time word-by-word LLM token generation) rather than blocking for 15–20 seconds while search and extraction finish.
2. **Transparent Telemetry**: Explicit visibility into search, extraction, and synthesis latencies, token consumption, and per-query USD costs.
3. **Decoupled Architecture**: Direct consumption of the canonical `search_proxy` package (`SearxngAdapter`, `ContentExtractor`, `SynthesisService`) without duplicating business logic.
4. **Bring Your Own Key (BYOK) & Sovereignty**: Flexible credential routing allowing users to supply their own cloud API keys (OpenRouter/OpenAI/Gemini) or connect to local inference endpoints (Ollama/vLLM at `localhost:11434`), falling back to server environment variables.
5. **Permissive Licensing**: Pure open-source, non-restrictive stack (MIT / BSD).

## Decision

### 1. Technology Stack: FastAPI + Uvicorn

Adopt **FastAPI** as the application framework and **Uvicorn** as the ASGI (Asynchronous Server Gateway Interface) web server:
- **Asynchronous Concurrency**: Built on Python's `asyncio` and `starlette`, enabling high-concurrency handling of long-lived HTTP connections required for streaming without blocking the server thread pool.
- **Automatic OpenAPI / Swagger Documentation**: Generates interactive documentation (`/docs` and `/redoc`) and JSON schema natively from Pydantic models.
- **Permissive Open Source**: Both FastAPI and Uvicorn are licensed under standard BSD / MIT licenses, adhering to `AGENTS.md`.

### 2. API Endpoints Specification

| Method | Endpoint | Description | Response Content-Type |
| :--- | :--- | :--- | :--- |
| `GET` | `/api/health` | Verifies SearXNG (`http://localhost:8080`) and LLM endpoint availability. | `application/json` |
| `POST` | `/api/search` | Synchronous end-to-end search, extraction, and synthesis. | `application/json` |
| `GET` | `/api/search/stream` | Real-time reactive Server-Sent Events (SSE) pipeline stream. | `text/event-stream` |
| `GET` | `/api/models` | Lists recommended models, context windows, and token pricing rates. | `application/json` |

### 3. Server-Sent Events (SSE) Streaming Lifecycle

When a client queries `/api/search/stream?q=...`, the server executes an asynchronous event generator emitting typed SSE messages:
1. `event: status` — Payload: `{"stage": "search", "message": "Searching SearXNG..."}`
2. `event: search_results` — Payload: List of found results (titles, domains, URLs).
3. `event: status` — Payload: `{"stage": "extract", "message": "Extracting full text from sources..."}`
4. `event: extraction_complete` — Payload: Extracted document counts and HTTP status statistics.
5. `event: status` — Payload: `{"stage": "synthesis", "message": "Synthesizing verified grounded answer..."}`
6. `event: token` — Emitted continuously per token chunk generated by the LLM stream.
7. `event: citations` — Payload: Array of structured `[Title](URL)` citations extracted from the complete text.
8. `event: telemetry` — Payload: Precise stage latencies (`search_ms`, `extract_ms`, `synthesis_ms`), token usage, and exact cost in USD.
9. `event: done` — Signal marking stream completion.

### 4. Credential Hierarchy and Bring Your Own Key (BYOK)

To guarantee local privacy sovereignty and avoid vendor lock-in, client requests may override server defaults via HTTP headers:
- `X-LLM-API-Key`: Custom API key (e.g., OpenRouter or OpenAI).
- `X-LLM-Base-URL`: Custom endpoint (e.g., `http://localhost:11434/v1` for local Ollama).
- `X-LLM-Model`: Custom model identifier (e.g., `qwen2.5:7b` or `meta-llama/llama-3.2-3b-instruct`).

If these headers are omitted, the service falls back gracefully to the server's `.env` configuration.

### 5. Concurrency Model

Synchronous network I/O from `SearxngAdapter.search()` and `ContentExtractor.extract_many()` will be dispatched via `asyncio.to_thread()` to prevent blocking the async event loop during web scraping. LLM synthesis will consume chunked streaming completions over `httpx.AsyncClient`.

## Consequences

- **Enables Modern Web UI**: The frontend (Friday milestone) can display live search progress, show source links before the LLM finishes typing, and stream words in real time.
- **Standardized Programmatic Access**: External agents and scripts can query the engine over standard HTTP REST endpoints with OpenAPI validation.
- **Telemetry Transparency**: Every query surfaces its exact token cost and performance breakdown to the client.
