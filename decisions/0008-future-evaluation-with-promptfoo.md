# 0008 — Future Evaluation with Promptfoo

**Status:** Proposed (recorded as an option to revisit)
**Date:** 2026-09-01

## Context

Two evaluation needs remain in the project: (a) systematically comparing candidate local models from [0003](0003-llm-model-architecture.md), and (b) formalizing an automated scoring rubric for answers generated by the synthesis pipeline. **Promptfoo** was evaluated as a candidate framework for both.

## What it is

An open-source (MIT core) LLM evaluation and red-teaming framework: a CLI that runs test cases (prompts + assertions) against one or more "providers" (OpenAI, Anthropic, Bedrock, and any OpenAI-compatible API endpoint — including local LM Studio, Ollama, or vLLM instances) and compares outputs side-by-side.

## Potential Integration Points

1. **Model Comparison ([0003](0003-llm-model-architecture.md))**: Use `prompts/prompts_v1.yaml` as test cases to systematically benchmark local candidate models (Qwen 2.5, Llama 3.x, Mistral) via LM Studio/Ollama, comparing citation accuracy and instruction-following.
2. **Automated Rubric ([0006](0006-search-evaluation-methodology.md))**: Once the response pipeline is complete, Promptfoo could run automated assertions on groundedness and formatting.

## Governance Note

Promptfoo was acquired by OpenAI in early 2026. The core CLI remains MIT/open-source and does not require telemetry or mandatory OpenAI API connectivity when running against local endpoints. Recorded as an ecosystem detail to monitor, rather than a technical blocker.

## Decision

**Not adopted yet.** Recorded as a concrete option when systematic multi-model benchmarking or automated assertion testing begins.

## Consequences

- If adopted, configure using local/self-hosted providers to preserve privacy ([0004](0004-conversation-privacy-and-security.md)).
