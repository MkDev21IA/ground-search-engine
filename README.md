# Ground Search Engine (with Verifiable Citations & Sources)

Open-source search and factual synthesis engine (LLM) focused on **rigorously grounded knowledge**: virtually every substantive claim generated by the model is accompanied by a verifiable primary or secondary source, cited inline in markdown format `[Source Title](URL)`.

---

## 🎯 Objective

Commercial LLMs frequently respond to research queries with hallucinations or vague lists of disconnected links at the end of their output, lacking provenance for individual statements.

This project addresses this challenge through a transparent, deterministic pipeline:
1. **Canonical Search**: Queries search engines without personal tracking via a local SearXNG instance.
2. **Ethical Content Extraction**: Clean fetching and parsing of HTML pages ([`trafilatura`](https://github.com/adbar/trafilatura)) and PDF reports ([`pypdf`](https://github.com/py-pdf/pypdf)), respecting `robots.txt` and polite request headers.
3. **Graceful Degradation (Anti-Overfitting)**: If a target page fails due to WAF blocking or timeout, the engine smoothly falls back to the search snippet, ensuring the model always has grounding context.
4. **Factual Synthesis with Inline Citations**: The model is prompted under strict groundedness rules, aggregating multiple perspectives, acknowledging information gaps when sources do not answer the question, and refusing to fabricate claims.
5. **Universal LLM Protocol**: Lightweight HTTP client over `httpx` based on the standard OpenAI Chat Completions specification (`/chat/completions`), natively compatible with Google Gemini (`gemini-2.5-flash`), OpenAI, and offline local inference servers (LM Studio, Ollama, vLLM).

## 🚀 Getting Started

### 1. Prerequisites
- Python 3.11+
- Docker and Docker Compose (for the local SearXNG instance)

### 2. Start the Local Search Engine
```bash
cd search-proxy
docker compose up -d
```
SearXNG will be accessible at `http://localhost:8080`.

### 3. Setup Python Virtual Environment
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
```

### 4. Configure Environment Variables
Copy the environment template:
```bash
cp .env.example .env
```
By default, the system uses `gemini-2.5-flash` via Google's OpenAI-compatibility endpoint (high throughput and low token cost). Set `LLM_API_KEY` with your Google AI Studio API key, or point `LLM_BASE_URL` to your local LM Studio instance (`http://localhost:1234/v1`).

### 5. Run the Test Suite
```bash
python -m pytest -v
```
